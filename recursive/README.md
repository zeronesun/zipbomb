# 经典递归 zip 炸弹（42.zip）

本目录集中存放经典的**递归** zip 炸弹 `42.zip` 的两种版本，与 `../zip/`
目录下由本项目 `zipbomb` 生成器产出的**非递归**炸弹区分开。

## 两种版本

| 版本 | 文件 | 大小 | 密码 | 说明 |
|------|------|------|------|------|
| 密码版（新版） | `password/42.password.zip` | 42,838 B | `42` | unforgettable.dk 新版本，需密码解压 |
| 免费版（旧版） | `free/42.zip` | 42,374 B | 无 | unforgettable.dk 旧版本，无需密码 |

## 结构

    recursive/
    ├── README.md          # 本文件
    ├── password/          # 密码版（42,838 B，密码 "42"）
    │   ├── 42.password.zip
    │   └── README.md
    └── free/              # 免费无密码版（42,374 B）
        ├── 42.zip
        └── README.md

## 安全警告

**绝对不要解压、双击，或让任何工具（文件管理器预览、杀软扫描等）自动解压
这些文件。**

经典递归炸弹的层级结构：5 层 × 每层 16 个嵌套 zip，最内层每文件约 4.3 GB。
完整解压后总体积约为 **4.5 PB（≈ 4,503,599,626,321,920 字节）**，会瞬间撑爆磁盘。

    | 层级 | 累计解压体积 |
    |------|--------------|
    | 1    | 68 GB        |
    | 2    | 1 TB         |
    | 3    | 17 TB        |
    | 4    | 281 TB       |
    | 5    | 4.5 PB       |

## 与本项目非递归炸弹的区别

本项目 `zipbomb` 生成器产出的是**非递归**炸弹（如 `../zip/zbsm.zip`、
`../zip/zblg.zip`），其原理是让大量文件条目共享同一个高度压缩的 DEFLATE
内核（文件重叠 / 引用重叠），因此即使解压器**不递归**展开内层 zip 也会触发
膨胀。两者都是研究 zip 解析器健壮性（DoS）的素材，请勿用于真实攻击。

## 查看压缩比（不解压）

可用项目根目录的 `ratio` 脚本只读归档头计算压缩比（不会解压文件内容）：

    python3 ratio recursive/password/42.password.zip
    python3 ratio recursive/free/42.zip
